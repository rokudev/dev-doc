Extends [StdDlgItemBase](doc:std-dlg-item-base)

The **StdDlgGraphicItem** node is used to display an image in the dialog's content area with an optional text label displayed to the left, right, above, or below the image. It should only be used as a child of a [**StdDlgContentArea**](doc:std-dlg-content-area) node.
