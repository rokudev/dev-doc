Extends [Group](doc:group)

**StdDlgItemBase** is the base class for all the content area items. It provides the common functionality for all StdDlg[*x*]Item nodes (for example, [**StdDlgBulletTextItem**](doc:std-dlg-bullet-text-item), [**StdDlgTextItem**](doc:std-dlg-text-item), [**StdDlgKeyboardItem**](doc:std-dlg-keyboard-item), [**StdDlgProgressItem**](doc:std-dlg-progress-item), [**StdDlgGraphicItem**](doc:std-dlg-graphic-item), and the other dialog building block nodes).
