Roku admite los siguientes valores de función para miembros del equipo de filmación, a los que se hace referencia mediante el campo `role` en cualquier lugar donde se entreguen metadatos del equipo de filmación (consulta las referencias de metadatos en XML y Excel para película, serie de TV y clip). **Las funciones distinguen entre mayúsculas y minúsculas** — entrégalas exactamente como se indican a continuación.

> **Nota entre formatos:** por el momento, Director es la **única** función del equipo de filmación admitida para la ingesta de metadatos en **Excel**. La lista completa a continuación aplica a la entrega en **XML**.

| Función del equipo de filmación |
| ------------------------------- |
| Actor                           |
| Anchor                          |
| Host                            |
| Narrator                        |
| Voice                           |
| Director                        |
| Producer                        |
| Screenwriter                    |
