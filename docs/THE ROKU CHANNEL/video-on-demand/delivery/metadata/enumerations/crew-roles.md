Roku supports the following crew member role values, referenced by the `role` field wherever crew metadata is delivered (see the Film/TV/Clip XML and Excel metadata references). **Roles are case-sensitive** — deliver exactly as listed below.

> **Cross-format note:** Director is currently the **only** crew role supported for **Excel** metadata ingest. The full list below applies to **XML** delivery.

| Crew Role    |
| ------------ |
| Actor        |
| Anchor       |
| Host         |
| Narrator     |
| Voice        |
| Director     |
| Producer     |
| Screenwriter |
