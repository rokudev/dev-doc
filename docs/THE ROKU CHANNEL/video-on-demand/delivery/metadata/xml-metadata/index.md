## Overview

This page is a **resource index** for Roku's XML metadata delivery. Schema downloads and annotated samples for each content type. It does not itself contain field-level requirements; those live on the dedicated per-content-type sub-pages:

- [**Roku XML: Film**](https://developer.roku.com/dev/update/docs/xml-film-metadata-fields)
- [**Roku XML: TV**](https://developer.roku.com/dev/update/docs/xml-episodic-tv-metadata-fields)
- [**Roku XML: Clip**](https://developer.roku.com/dev/update/docs/xml-shortform-clip-metadata-fields)

Use this page to locate the correct schema and sample files while working from those sub-pages.
