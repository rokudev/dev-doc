## About this lesson

This lesson introduces the Roku SceneGraph development course. It lists the requirements for developing on the Roku platform, which includes creating a Roku user account, enrolling in the Roku developer program, and getting a Roku device for development and testing. It concludes by providing the course syllabus and highlighting the app UI and features you will learn to build.
