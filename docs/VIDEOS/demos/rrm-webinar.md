In September 2022, Roku demonstrated how developers can use the Roku Resource Monitor to identify resource consumption trends and patterns in their apps. Topics covered in this webinar include:

- Why the Roku Resource Monitor is an important tool for testing apps.
- The public ECP commands that power the tool.
- The different resource consumption metrics tracked by the tool.  
- The different modes of operation.

The webinar featured a demo showing how to use the tool to monitor the memory, CPU, and node usage on a sideloaded app.
